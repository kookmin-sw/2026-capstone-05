# 상점 우하단 액션 버튼 숨김 처리

## Summary
- 상점 오른쪽 하단의 `Buy/Sell` 버튼 영역과 배치 모드의 `Place/Cancel` 버튼 영역을 보이지 않게 숨긴다.
- 기능 수정은 하지 않고, 화면에서 노출되지 않도록 처리한다.
- 상점 카탈로그, 구매 팝업, 배치 그리드, NPC 이미지는 그대로 유지한다.

## Key Changes
- `ShopView.cs`에서 버튼 컨테이너 두 개를 항상 숨김 상태로 유지한다.
  - `main-action-buttons`: `Buy/Sell`
  - `placement-action-buttons`: `Place/Cancel`
- 초기화 직후 두 컨테이너에 `DisplayStyle.None`을 적용한다.
- `SwitchToPlacementMode()`에서 기존 `placementActionButtons.style.display = DisplayStyle.Flex`를 `DisplayStyle.None`으로 바꾼다.
- `SwitchToCatalogMode()`에서 기존 `mainActionButtons.style.display = DisplayStyle.Flex`를 `DisplayStyle.None`으로 바꾼다.
- UXML 구조와 버튼 이벤트 연결은 최소한으로 유지해서 다른 코드 참조(`GetCancelPlaceButton`)가 깨지지 않게 한다.

## Test Plan
- 상점 기본 화면에서 오른쪽 하단 `Buy/Sell` 버튼 박스가 보이지 않는지 확인한다.
- 아이템 구매 팝업에서 구매 확정 후 배치 화면으로 넘어가도 오른쪽 하단 `Place/Cancel` 버튼 박스가 보이지 않는지 확인한다.
- 카탈로그, 골드 표시, NPC, 구매 팝업 Confirm/Cancel은 기존처럼 보이는지 확인한다.
- 콘솔에 null reference 오류가 없는지 확인한다.

## Assumptions
- 숨길 대상은 오른쪽 하단의 큰 액션 버튼 컨테이너 전체다.
- 아이템 클릭 시 뜨는 구매 팝업의 `[BUY] Confirm`, `[CANCEL]` 버튼은 이번 대상이 아니다.
- 동작하지 않는 기능을 고치는 작업은 하지 않고, 노출만 막는다.
