# 상점 배치 창을 구매 창 크기 그대로 사용

## Summary
- 이전 계획의 임의 고정값 `640x900`은 제거한다.
- 배치 모드 왼쪽 창은 구매 화면에서 실제로 보이던 `left-panel` 크기를 그대로 복사해서 사용한다.
- 즉, 구매 화면의 카탈로그 패널 크기/위치를 기준으로 배치 그리드만 그 안에 넣는다.

## Key Changes
- `ShopView.cs`의 잘못된 고정 크기 변경을 되돌린다.
  - `leftPanel.style.width = 640`
  - `leftPanel.style.height = 900`
  - `leftPanel.style.alignSelf = Align.Center`
  - 위 임의 스타일은 제거한다.
- 구매 화면 상태에서 `left-panel`의 실제 resolved 크기를 저장한다.
  - `catalogLeftPanelWidth = leftPanel.resolvedStyle.width`
  - `catalogLeftPanelHeight = leftPanel.resolvedStyle.height`
- `SwitchToPlacementMode()`에서는 저장한 구매 창 크기를 그대로 적용한다.
  - `leftPanel.style.flexGrow = 0`
  - `leftPanel.style.width = catalogLeftPanelWidth`
  - `leftPanel.style.height = catalogLeftPanelHeight`
- `placement-grid-container`는 그 구매 창 크기 안을 채우게 한다.
  - `display = Flex`
  - `flexGrow = 1`
  - `width = 100%`
  - `height = 100%`
- `SwitchToCatalogMode()`에서는 구매 화면 원래 스타일로 복구한다.
  - `leftPanel.style.flexGrow = 1`
  - `leftPanel.style.width = 50%`
  - `leftPanel.style.height = auto`
- 우하단 `Buy/Sell`, `Place/Cancel` 버튼 숨김 처리는 유지한다.

## Test Plan
- 상점 구매 화면에서 왼쪽 카탈로그 창 크기를 확인한다.
- 구매 후 배치 모드로 넘어갔을 때 검은 배치 창이 구매 화면 왼쪽 창과 같은 크기/위치로 보이는지 확인한다.
- 배치 그리드와 드래그 아이템이 그 창 안에서 정상 표시되는지 확인한다.
- 배치 완료/취소 후 구매 화면으로 돌아왔을 때 카탈로그 창 크기가 원래대로 복구되는지 확인한다.

## Assumptions
- “그대로 베끼기”는 구매 화면의 왼쪽 `left-panel` 실제 크기를 배치 모드에서도 그대로 쓰는 의미다.
- 상점 기능이나 배치 판정은 건드리지 않고, 창 크기/레이아웃만 수정한다.
