# 아이템 설명창 타이틀 제거 및 상단 배치 조정

## Summary
- `ITEM DETAILS` 텍스트는 제거한다.
- `iteminfo_frame` 이미지는 그대로 유지한다.
- 아이템 아이콘, 이름, 가격 줄을 프레임 안쪽에서 더 위로 올려 배치한다.

## Key Changes
- `Assets/Resources/UI/ItemDescriptionPanel.uxml`에서 `ITEM DETAILS` 라벨을 제거한다.
  - `.item-description-header` 컨테이너는 구조 안정성을 위해 남기되 비표시 처리한다.
- `Assets/Resources/UI/ItemDescriptionPanel.uss`에서 헤더 공간을 없앤다.
  - `.item-description-header { display: none; height: 0; }`
  - `.item-description-title` 스타일은 제거하거나 더 이상 쓰이지 않게 둔다.
- 본문을 프레임 상단 영역으로 올린다.
  - `.item-description-body` padding을 `24px 34px 18px 34px` 기준으로 조정한다.
  - `.item-description-info`는 상단 여백 없이 바로 시작하게 한다.
  - 아이콘/이름/가격은 현재 크기 유지하되, 프레임 왼쪽 경사와 겹치지 않도록 좌우 padding만 조금 넓힌다.
- 하단 정보는 현재보다 과하게 밀리지 않게 정돈한다.
  - 모양 미리보기 영역 높이는 유지 또는 소폭 축소한다.
  - 수량/설명은 프레임 안쪽 하단에 남기되, 위로 올라간 상단 정보와 겹치지 않게 margin만 조정한다.

## Test Plan
- 아이템 hover 시 `ITEM DETAILS` 문구가 보이지 않는지 확인한다.
- 핫팩 아이콘, `핫팩`, `40 Gold`가 기존보다 위에 있고 프레임 안쪽에 자연스럽게 들어가는지 확인한다.
- 인벤토리, 상자/루팅, 퀵슬롯 hover에서 같은 설명창 배치가 적용되는지 확인한다.
- 긴 아이템명/설명에서도 프레임 밖으로 밀리거나 수량/설명과 겹치지 않는지 확인한다.

## Assumptions
- 타이틀은 완전히 제거하는 것이 맞고, 빈 상단 제목 영역도 남기지 않는다.
- 프레임 이미지와 설명창 바깥 크기/위치는 변경하지 않는다.
- 이번 수정은 UXML/USS 레이아웃만 대상으로 하며, 설명창 표시/드래그 잠금 로직은 건드리지 않는다.
