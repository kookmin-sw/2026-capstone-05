# 드래그 중 아이템 설명창이 사라지는 문제 원인 및 수정 계획

## Summary
- 원인은 드래그 중 다른 `GridItemView`의 hover 이벤트가 설명창 소유자를 빼앗은 뒤 `PointerLeave`에서 숨기는 이벤트 경합이다.
- 설명창은 드래그 시작 아이템에 고정하고, 드래그 중 다른 아이템 hover는 설명창을 건드리지 않게 만든다.

## Key Changes
- `GridItemView.OnPointerEnter`에서 `GridItemView.IsAnyItemDragging == true`이고 현재 뷰가 드래그 중인 아이템이 아니면 `ItemDescriptionPanelController.Show`를 호출하지 않는다.
- `GridItemView.OnPointerLeave`도 드래그 중에는 다른 아이템이 `Hide`를 호출하지 않게 막는다.
- 기존 의도대로 드래그 시작 시 설명창은 유지하고, 드래그 종료/취소/분할/강제 리셋 시에는 기존 `Hide` 흐름을 그대로 둔다.
- 퀵슬롯 드래그는 이미 자체 `isDragging && draggingSlotIndex == slotIndex` 가드가 있으므로 우선 변경하지 않는다.

## Test Plan
- 인벤토리에서 아이템을 드래그한 채 다른 아이템 위를 지나가도 설명창이 사라지지 않는지 확인한다.
- 상자/루팅 UI에서 아이템을 드래그해 인벤토리/상자 양쪽 아이템 위를 지나가도 설명창이 유지되는지 확인한다.
- 드래그 종료, 우클릭 분할 취소, 강제 리셋 시 설명창이 정상적으로 사라지는지 확인한다.
- 드래그하지 않는 일반 hover에서는 기존처럼 아이템별 설명창이 정상 표시/숨김 되는지 확인한다.

## Assumptions
- 원하는 동작은 “드래그 중에는 드래그 시작 아이템 설명을 유지”하는 것이다.
- 설명창 내용이 드롭 후보 아이템으로 바뀌는 동작은 의도하지 않는다.
- 수정 대상은 `GridItemView.cs`의 hover 가드로 한정한다.
