# 상점 배치 모드 인벤 창 축소

## Summary
- 구매 후 인벤토리에 배치하는 화면에서 왼쪽 배치 창이 너무 크게 늘어나는 문제를 줄인다.
- 배치 모드에서는 왼쪽 패널을 고정 크기 창처럼 만들고, 카탈로그 모드로 돌아가면 기존 구매 화면 레이아웃으로 복구한다.
- 배치 로직과 아이템 드래그 로직은 건드리지 않는다.

## Key Changes
- `ShopView.cs`에 `left-panel` 참조를 추가한다.
- `SwitchToPlacementMode()`에서 왼쪽 패널을 배치 전용 크기로 고정한다.
  - `leftPanel.style.flexGrow = 0`
  - `leftPanel.style.width = 640px`
  - `leftPanel.style.height = 900px`
  - `leftPanel.style.alignSelf = Align.Center`
- `placement-grid-container`는 더 이상 빈 공간을 전부 채우지 않게 한다.
  - `flexGrow = 0`
  - `width = 100%`
  - `height = 100%`
- `SwitchToCatalogMode()`에서는 왼쪽 패널을 기존 구매 화면 크기로 되돌린다.
  - `flexGrow = 1`
  - `width = 50%`
  - `height = auto`
  - `alignSelf` 초기화
- 기존에 숨긴 우하단 `Buy/Sell`, `Place/Cancel` 버튼 숨김 상태는 유지한다.

## Test Plan
- 상점 기본 구매 화면에서 왼쪽 카탈로그 패널 크기가 기존처럼 유지되는지 확인한다.
- 아이템 구매 확정 후 배치 모드에서 검은 인벤 배치 창이 현재보다 약 절반 폭으로 줄어드는지 확인한다.
- 배치 모드에서 인벤 슬롯과 드래그 중인 아이템이 잘 보이고 클릭/배치 판정이 유지되는지 확인한다.
- 배치 취소 또는 배치 완료 후 카탈로그 모드로 돌아왔을 때 패널 크기가 정상 복구되는지 확인한다.

## Assumptions
- “절반 정도 크기”는 현재 배치 모드의 과도하게 넓은 왼쪽 창 폭을 약 640px 기준으로 줄이는 의미로 적용한다.
- 슬롯 전체를 한 화면에 보이게 하기 위해 높이는 900px로 유지한다.
- 상점 기능 수정은 하지 않고, 배치 모드 창 크기만 조정한다.
