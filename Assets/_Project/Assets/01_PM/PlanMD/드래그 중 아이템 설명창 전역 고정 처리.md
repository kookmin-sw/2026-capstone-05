# 드래그 중 아이템 설명창 전역 고정 처리

## Summary
- 설명창을 “드래그 시작 아이템”에 전역으로 고정해, 인벤/상자/퀵슬롯 어디를 지나가도 다른 hover가 설명창을 빼앗거나 숨기지 못하게 한다.
- 인벤/상자 전용 가드와 퀵슬롯 전용 가드를 따로 늘리는 대신, `ItemDescriptionPanelController`에 드래그 잠금 상태를 추가해 모든 UI 이동 경로를 한 번에 막는다.

## Key Changes
- `ItemDescriptionPanelController`에 드래그 잠금 API를 추가한다.
  - `BeginDragLock(ItemInstance item, VisualElement owner)`: 설명창을 표시하고 현재 owner를 잠근다.
  - `EndDragLock(VisualElement owner, bool hide = true)`: 잠근 owner가 맞을 때만 잠금을 해제하고 기존처럼 숨긴다.
  - 잠금 중 `Show`는 잠금 owner가 아닌 요청을 무시한다.
  - 잠금 중 `Hide`는 잠금 owner가 아닌 요청을 무시한다.
  - `HideImmediate`는 강제 초기화 용도이므로 잠금도 함께 해제한다.
- `GridItemView.cs`는 드래그 시작 시 `Show` 대신 `BeginDragLock`을 호출한다.
  - 일반 hover `Show/Hide`는 유지한다.
  - `OnPointerUp`, `CancelDragState`, 강제 리셋/분할 취소 흐름에서는 `EndDragLock`으로 종료한다.
- `QuickslotUIController.cs`도 드래그 시작 시 `Show` 대신 `BeginDragLock`을 호출한다.
  - 퀵슬롯의 `OnPointerEnter/Leave`는 일반 hover용으로 유지하되, 잠금 중에는 컨트롤러가 다른 owner 요청을 무시한다.
  - `OnPointerUp`, 우클릭 분할 취소, `OnDisable/OnDestroy`에서는 잠금을 정상 해제한다.
- 기존 드롭/교환/스택/회전 로직은 건드리지 않는다.

## Test Plan
- 퀵슬롯 아이템을 다른 퀵슬롯 위로 드래그해도 설명창이 드래그 시작 아이템으로 유지되는지 확인한다.
- 퀵슬롯에서 인벤토리 아이템/빈칸/상자 아이템 위를 지나가도 설명창이 사라지거나 다른 아이템으로 바뀌지 않는지 확인한다.
- 인벤토리 ↔ 상자 드래그에서도 기존처럼 설명창이 유지되는지 확인한다.
- 드래그 종료, 드롭 실패, 우클릭 분할, UI 닫힘/비활성화 시 설명창이 정상적으로 사라지는지 확인한다.
- 드래그하지 않는 일반 hover에서는 인벤/상자/퀵슬롯 설명창 표시/숨김이 기존처럼 동작하는지 확인한다.

## Assumptions
- 원하는 동작은 “드래그 중에는 드래그 시작 아이템 설명창 유지”다.
- 드래그 중 지나가는 대상 아이템의 설명으로 바뀌는 동작은 의도하지 않는다.
- 수정 범위는 설명창 owner/잠금 처리와 드래그 시작·종료 호출부로 제한한다.
