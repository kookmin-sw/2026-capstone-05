# 아이템 설명창 텍스트 배치/크기 조정

## Summary
- `iteminfo_frame` 이미지는 그대로 유지하고, 설명창 내부 여백과 글자 크기만 조정한다.
- 현재 너무 위/왼쪽으로 붙고 작게 보이는 이름, 가격, 수량, 설명 텍스트를 프레임 안쪽 영역에 맞춰 키우고 정렬한다.
- UXML 구조와 표시/숨김 로직은 건드리지 않는다.

## Key Changes
- `Assets/Resources/UI/ItemDescriptionPanel.uss` 중심으로 수정한다.
  - `.item-description-box`는 `width: 520px` 유지, 프레임 비율에 맞게 `min-height: 232px`를 추가한다.
  - 박스 전체 padding은 제거하고, 헤더/본문에서 직접 위치를 잡는다.
  - `.item-description-header`는 프레임 상단 바 높이에 맞춰 `height: 56px`, 중앙 정렬로 변경한다.
  - `.item-description-body`는 프레임 내부 안전 영역에 맞춰 `padding: 12px 28px 20px 28px`로 조정한다.
- 텍스트와 아이콘을 전체적으로 키운다.
  - 타이틀: `16px` → `18px`
  - 아이템명: `18px` → `22px`
  - 가격: `14px` → `16px`
  - 수량/설명: `13px` → `15px`
  - 아이콘: `56px` → `64px`
- 배치를 정돈한다.
  - 아이콘/이름/가격 줄은 프레임 내부 상단에 안정적으로 놓이게 하고, 이름/가격 간격을 약간 추가한다.
  - 모양 미리보기 영역은 중앙에 유지하되 높이를 줄여 텍스트와 겹치지 않게 한다.
  - 수량은 오른쪽 하단 근처, 설명은 왼쪽 하단 근처에 읽히는 위치로 둔다.
- `ItemDescriptionPanelController.cs`는 기본적으로 건드리지 않는다.
  - 모양 미리보기 셀 크기까지 작아 보이면 그때만 `ShapeCellSize`를 함께 키우는 후속 수정으로 분리한다.

## Test Plan
- 인벤토리 아이템 hover 시 설명창 프레임 안에 타이틀, 이름, 가격, 수량, 설명이 자연스럽게 들어가는지 확인한다.
- 상자/루팅 UI hover에서도 같은 배치가 유지되는지 확인한다.
- 긴 아이템명과 한글 설명이 프레임 밖으로 밀리거나 겹치지 않는지 확인한다.
- 드래그 중 설명창 유지/숨김 동작이 기존처럼 유지되는지 확인한다.

## Assumptions
- 프레임 이미지는 현재 `iteminfo_frame.png` 그대로 사용한다.
- 설명창의 바깥 크기와 화면 위치는 크게 바꾸지 않고, 내부 레이아웃만 조정한다.
- 이번 수정 대상은 글자 위치/크기이며, 설명창 동작 로직은 변경하지 않는다.
