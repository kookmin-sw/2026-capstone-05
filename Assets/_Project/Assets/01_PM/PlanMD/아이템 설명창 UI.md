# 아이템 설명창 공통 UI 계획

## 요약
- 설명창은 커서를 따라가지 않고, 사용자가 그려준 것처럼 화면 하단 중앙 고정 위치에 표시합니다.
- 마우스를 아이템 위에 올렸을 때 또는 아이템을 드래그 중일 때만 표시하고, 그 외에는 완전히 숨깁니다.
- 퀵슬롯, 인벤토리, 루팅 아이템 모두 같은 설명창 컨트롤러를 사용합니다.
- 표시 내용과 스타일은 상점 팝업을 기준으로 맞추되, 구매/판매 버튼과 수량 선택 UI는 제외합니다.

## 주요 변경
- UI Toolkit 기반으로 `UXML/USS` 설명창을 추가합니다.
  - Canvas 런타임 생성 방식은 쓰지 않습니다.
  - 설명창은 `position: absolute`로 루트 UI 위에 붙이고, 하단 중앙 고정 좌표에 배치합니다.
  - 상점 팝업의 베이지 배경, 갈색 헤더/테두리, 검은 본문 텍스트 스타일을 재사용하거나 동일하게 맞춥니다.

- 설명창 내용은 상점 아이템 상세 팝업을 참고합니다.
  - 아이템 이름: `ItemData.ItemNameString`
  - 설명: `ItemData.DescriptionString`
  - 가격: 상점 외부에서는 `ItemData.price` 기준으로 표시
  - 아이콘: 현재 슬롯에 보이는 아이템 아이콘 또는 `ItemData` 아이콘
  - 수량: 현재 아이템 인스턴스의 스택 수량
  - 상점 전용 요소인 구매/판매 확인 버튼, 취소 버튼, 수량 증감 버튼은 넣지 않습니다.

- 공통 컨트롤러를 추가합니다.
  - `Show(itemInstance, sourceElement)`로 아이템과 현재 UI 루트를 받아 설명창을 표시합니다.
  - `Hide(sourceElement)` 또는 `HideIfOwner(sourceElement)`로 해당 hover/drag 상태가 끝났을 때 숨깁니다.
  - 다른 UI 문서에서 호출돼도, 호출한 슬롯/아이템의 루트에 설명창을 붙여 정상 표시되게 합니다.

- 적용 지점
  - `GridItemView`: 인벤토리와 루팅 공통 아이템 뷰에 hover enter/leave, drag start/end 처리를 추가합니다.
  - `GridStorageView`: 드래그 취소, 강제 리셋, 아이템 제거 시 설명창이 남지 않도록 정리합니다.
  - `QuickslotUIController`: 퀵슬롯 아이템 hover 및 drag 중에도 같은 설명창을 표시합니다.

## 표시 규칙
- 표시됨:
  - 인벤/루팅/퀵슬롯 아이템에 마우스를 올린 상태
  - 인벤/루팅/퀵슬롯 아이템을 드래그 중인 상태

- 숨김:
  - 빈 슬롯 위에 있을 때
  - 아이템에서 마우스가 벗어났고 드래그 중이 아닐 때
  - 드래그가 끝났거나 취소됐을 때
  - 인벤토리/루팅 UI가 닫혔을 때
  - 슬롯 아이템이 제거되거나 다른 아이템으로 갱신됐을 때

## 테스트
- 인벤토리 아이템에 마우스를 올리면 하단 중앙 고정 설명창이 뜹니다.
- 루팅 아이템에 마우스를 올려도 같은 위치와 같은 스타일로 뜹니다.
- 퀵슬롯 아이템에 마우스를 올려도 같은 설명창이 뜹니다.
- 아이템을 드래그하는 동안 설명창이 유지됩니다.
- 드래그 종료, 빈 슬롯 이동, UI 닫기 후 설명창이 사라집니다.
- 설명창이 커서를 따라 움직이지 않습니다.
- 표시 텍스트가 상점 팝업의 이름/가격/설명 기준과 일치합니다.

## 가정
- “상점을 참고”는 상점 팝업의 아이템 이름, 가격, 설명, 아이콘, 색상/테두리 스타일을 따르되 상점 전용 구매 UI는 제외한다는 의미로 처리합니다.
- 가격은 상점 컨텍스트가 아닌 일반 아이템 설명창이므로 `ItemData.price`를 표시합니다.
- 위치는 스크린샷 기준 하단 중앙 고정이며, 슬롯이나 커서 위치에 따라 변하지 않습니다.
