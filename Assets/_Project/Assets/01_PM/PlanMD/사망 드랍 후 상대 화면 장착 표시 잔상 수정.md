# 사망 드랍 후 상대 화면 장착 표시 잔상 수정

## Summary
- 원인은 사망 드랍 로직에서 “아이템 드랍 권한”과 “플레이어 손의 장착 비주얼 해제”가 같이 묶여 있는 구조다.
- 현재 `DropInventoryAtDeathPosition()`은 입력 권한이 없는 플레이어 객체에서는 바로 return하므로, 호스트가 보는 클라이언트 복제본처럼 드랍 권한이 없는 쪽은 장착 해제가 실행되지 않을 수 있다.
- 그래서 아이템은 바닥에 떨어졌는데, 상대 화면에서는 죽은 플레이어 손에 아직 장착된 것처럼 보이는 상태가 남는다.

## Key Changes
- `PlayerRespawn.RespawnRoutine()`에서 사망 처리 시작 시점에 `controller.Equipment?.UnequipItem()`을 항상 먼저 호출한다.
  - 입력 권한 플레이어는 네트워크 장착 상태를 빈 값으로 동기화한다.
  - 권한 없는 복제본은 로컬 비주얼만 해제되어 상대 화면 잔상을 제거한다.
- `DropInventoryAtDeathPosition()`은 드랍 권한 판단과 바닥 드랍만 담당하게 정리한다.
  - `ShouldDropLocalInventoryOnDeath()`가 false여도 장착 해제는 이미 사망 루틴에서 처리되므로 손 비주얼이 남지 않는다.
  - 실제 아이템 드랍은 기존처럼 입력 권한 플레이어만 수행해 중복 드랍을 막는다.
- `suppressNextDeathDrop` 경로도 장착 해제는 동일하게 적용한다.
  - 라운드 종료 패널티/강제 스폰과 일반 사망 모두 장착 비주얼이 남지 않게 한다.
- 아이템 데이터의 `pickupPrefab`/`equipPrefab` 구조는 유지한다.
  - 바닥 아이템이 “장착 프리팹”으로 잘못 생성되는 문제가 아니라, 사망한 플레이어의 장착 상태 잔상이 핵심 원인으로 본다.

## Test Plan
- 호스트가 장착 아이템을 든 상태로 사망하면, 클라이언트 화면에서 손 장착 비주얼이 즉시 사라지고 바닥 드랍만 보이는지 확인한다.
- 클라이언트가 장착 아이템을 든 상태로 사망하면, 호스트 화면에서 손 장착 비주얼이 즉시 사라지고 바닥 드랍만 보이는지 확인한다.
- 퀵슬롯 선택 아이템, 인벤토리 아이템, 둘 다 가진 상태에서 사망 시 드랍 개수가 중복되지 않는지 확인한다.
- 사망 리스폰 후 플레이어가 맨손 상태로 보이고, 다시 아이템을 줍고 장착하면 호스트/클라 모두 정상 동기화되는지 확인한다.
- `dotnet build Assembly-CSharp.csproj` 또는 Unity 컴파일 오류가 없는지 확인한다.

## Assumptions
- “상대방이 봤을 때 장착된 것처럼 보임”은 바닥 드랍 아이템 모양 문제가 아니라, 죽은 플레이어의 손/3인칭 장착 비주얼이 남는 현상으로 처리한다.
- 실제 드랍 생성은 지금처럼 입력 권한 플레이어 한 명만 수행해야 한다.
- 사망 시 장착 해제는 인벤토리 드랍 여부와 무관하게 항상 수행되어야 한다.
