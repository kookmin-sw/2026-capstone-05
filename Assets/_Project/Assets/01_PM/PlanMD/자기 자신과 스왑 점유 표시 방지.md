# 자기 자신과 스왑/점유 표시 방지

## Summary
- 같은 그리드 안에서 드래그 아이템이 자기 기존 점유칸 위에 올라가도 스왑 후보로 보지 않는다.
- 인벤/상자 grid는 앵커칸이 아니라 기존 shape 전체를 자기 영역으로 판단한다.
- 퀵슬롯은 같은 슬롯 드롭을 no-op으로 유지하고, 같은 슬롯 하이라이트도 스왑처럼 보이지 않게 정리한다.

## Key Changes
- `GridInventoryController`에 self-overlap helper를 추가한다.
  - `ReferenceEquals(sourceModel, model)`일 때만 적용한다.
  - source item의 기존 anchor와 현재 rotation shape로 기존 점유 좌표를 만든다.
  - target shape가 자기 기존 점유 영역과만 겹치면 self-overlap으로 판단한다.
- grid 하이라이트에서 자기 자신은 스왑/점유 후보에서 제외한다.
  - 자기 기존 점유칸 위에서는 회색 스왑 후보를 표시하지 않는다.
  - 다른 아이템과 겹칠 때만 기존 스왑/스택 후보 표시를 유지한다.
- 실제 grid 드롭 처리도 같은 기준으로 보강한다.
  - 인벤 내부 이동과 상자 내부 이동 모두 자기 기존 shape 영역에 rotation 변화 없이 드롭하면 `RevertDrop`으로 무동작 처리한다.
  - 다른 위치로 이동하거나 다른 아이템과 겹치는 경우 기존 이동/스왑/스택 로직을 유지한다.
- 퀵슬롯은 명시적으로 self-drop을 no-op 처리한다.
  - `QuickslotUIController.CanDropOnQuickslot`에서 `source == Quickslot && sourceIndex == targetQuickslotIndex`는 유효 드롭 하이라이트를 띄우지 않게 한다.
  - `ReceiveDrop`의 같은 슬롯 no-op/rotation restore 동작은 유지한다.
  - grid ↔ quickslot 이동은 source/target 저장소가 다르므로 grid self-overlap helper 대상에서 제외한다.

## Test Plan
- 2칸 이상 아이템을 자기 기존 몸통 칸 위로 드래그해도 회색 스왑 후보가 뜨지 않는지 확인한다.
- 자기 기존 영역에 그대로 드롭하면 이동/스왑 없이 원래 상태로 유지되는지 확인한다.
- 자기 영역 밖 빈칸으로 이동하면 기존처럼 초록 하이라이트와 이동이 동작하는지 확인한다.
- 다른 아이템 위로 드래그하면 기존처럼 스왑/스택 후보가 표시되는지 확인한다.
- 퀵슬롯 아이템을 같은 퀵슬롯 위로 드래그했을 때 스왑처럼 보이는 하이라이트가 뜨지 않고, 드롭 후 원래 상태가 유지되는지 확인한다.
- 퀵슬롯 ↔ 인벤, 퀵슬롯 ↔ 상자 이동은 기존처럼 동작하는지 확인한다.

## Assumptions
- 자기 기존 점유칸 위 드롭은 스왑이 아니라 무동작이다.
- 퀵슬롯 같은 슬롯 드롭도 무동작이며, 성공 하이라이트를 보여줄 필요가 없다.
- 다른 아이템과의 스왑/스택 로직은 유지한다.
