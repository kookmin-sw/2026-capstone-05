# 아이템 설명창 4x4 점유 격자 미리보기

## Summary
- 설명창의 아이템 모양 미리보기를 항상 4x4 격자로 표시한다.
- 4x4의 기본 칸은 어두운 빈칸으로 보이고, 아이템이 차지하는 칸만 기존 흰색 칸으로 표시한다.
- 아이템 shape 좌표는 4x4 안에 자동 정규화해서 넣는다.

## Key Changes
- `ItemDescriptionPanelController.DrawShape`를 4x4 고정 렌더링으로 바꾼다.
  - `ShapePreviewGridSize = 4` 상수를 추가한다.
  - 회전된 `positions`의 `minX/minY`를 기준으로 좌표를 `0..3` 범위 시작점에 맞춘다.
  - 16개 셀을 항상 생성하고 `.item-description-shape-cell` 클래스를 붙인다.
  - 점유 좌표에 해당하는 셀에만 `.item-description-shape-cell--occupied` 클래스를 추가한다.
- 4x4 전체 크기가 중앙에 보이도록 grid 크기를 고정한다.
  - `shapeGrid.style.width = 4 * stride - gap`
  - `shapeGrid.style.height = 4 * stride - gap`
- `ItemDescriptionPanel.uss`에서 기본/점유 칸 스타일을 분리한다.
  - `.item-description-shape-cell`: 어두운 반투명 빈칸, 얇은 어두운 테두리
  - `.item-description-shape-cell--occupied`: 현재 흰색/연회색 칸 스타일
- 4x4를 넘는 shape가 들어오면 4x4 안에 들어오는 칸만 표시하고 나머지는 무시한다.
  - 현재 아이템이 4x4 이하라는 전제라 별도 에러 처리나 스케일 다운은 하지 않는다.

## Test Plan
- 1칸 아이템이 4x4 검은 격자 안의 흰색 1칸으로 표시되는지 확인한다.
- 1x2, 2x2, 세로/가로 직사각형 아이템이 4x4 안에서 점유칸만 흰색으로 표시되는지 확인한다.
- 아이템 회전 상태가 설명창 미리보기에도 반영되는지 확인한다.
- 인벤토리, 상자/루팅, 퀵슬롯 hover 설명창에서 같은 4x4 미리보기가 보이는지 확인한다.
- 설명, 수량, 가격 텍스트와 격자가 겹치지 않는지 확인한다.

## Assumptions
- 현재 아이템 shape는 4x4를 넘지 않는다.
- 4x4의 빈칸은 검은/어두운 배경, 점유칸은 기존 흰색 칸으로 보이게 한다.
- 설명창 레이아웃과 드래그/hover 동작은 변경하지 않고, shape preview 렌더링만 변경한다.
