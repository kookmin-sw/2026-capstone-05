# 퀵슬롯 크기 소폭 확대

## Summary
- 하단 퀵슬롯 4개를 현재 `60px`에서 `66px`로 조금 키운다.
- 슬롯 묶음은 화면 중앙 정렬을 유지한다.
- 아이템 드래그/드롭 로직은 건드리지 않고, UI 크기와 배치만 조정한다.

## Key Changes
- `QuickslotUI.uss`에서 슬롯 크기를 키운다.
  - `.quickslot` `width/height: 60px` → `66px`
  - `.bottom-center-panel` `width: 270px` → `294px`
  - `.bottom-center-panel` `height: 70px` → `76px`
  - 중앙 정렬 유지를 위해 `left: 825px` → `813px`
  - 하단 위치 유지를 위해 `top: 990px` → `984px`
- `QuickslotUI.uxml`의 절대 배치 간격을 새 크기에 맞춘다.
  - `Quickslot0 left: 0`
  - `Quickslot1 left: 76px`
  - `Quickslot2 left: 152px`
  - `Quickslot3 left: 228px`
- 번호 라벨은 슬롯 증가에 맞춰 살짝 키운다.
  - `.quickslot-number font-size: 12px` → `13px`
  - 기존 우상단 위치와 스타일은 유지한다.
- `QuickslotUIController.cs`의 드래그/설명창/아이템 이동 로직은 변경하지 않는다.

## Test Plan
- 하단 퀵슬롯이 기존보다 약간 커졌고 화면 중앙에 유지되는지 확인한다.
- 1~4 번호 라벨이 슬롯 안에 잘 들어가는지 확인한다.
- 퀵슬롯 아이콘 표시, hover 설명창, 드래그 시작/드롭 판정이 기존처럼 동작하는지 확인한다.
- 인벤토리/상자 UI가 열려 있을 때 퀵슬롯이 너무 가깝거나 겹치지 않는지 확인한다.

## Assumptions
- “조금”은 `60px`에서 `66px`로 약 10% 확대하는 의미로 적용한다.
- 슬롯 간 간격은 기존처럼 `10px` 유지한다.
- 퀵슬롯 드래그 고스트 크기는 아이템 모양 기반으로 계산되므로 이번 범위에서 변경하지 않는다.
