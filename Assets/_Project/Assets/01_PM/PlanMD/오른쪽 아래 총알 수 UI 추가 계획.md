**오른쪽 아래 총알 수 UI 추가 계획**

**요약**
- 장착 중인 아이템이 총기일 때, 화면 오른쪽 아래에 `TMP` 텍스트로 남은 총알 수를 표시합니다.
- 현재 총기 시스템은 탄창 수를 따로 저장하지 않고 발사할 때마다 인벤토리/퀵슬롯의 탄약 아이템을 1개 소모하므로, UI에는 **현재 장착한 총기가 요구하는 탄약의 전체 보유량**을 표시합니다.

**주요 변경**
- 새 런타임 HUD 컴포넌트 `AmmoCountUI`를 `Assets/_Project/Scripts/04_UI/Ingame UI/`에 추가합니다.
  - `RuntimeInitializeOnLoadMethod`로 자동 생성되게 하여 씬에 수동 배치가 없어도 동작하게 합니다.
  - `ScreenSpaceOverlay` Canvas, `CanvasScaler`, `TextMeshProUGUI`를 코드로 생성합니다.
  - 오른쪽 아래 기준 위치: anchor/pivot `(1, 0)`, offset `(-44, 42)` 정도로 퀵슬롯 중앙 UI와 겹치지 않게 배치합니다.
- 로컬 플레이어의 `PlayerEquipment.CurrentItemInstance`를 읽어 현재 장착 아이템이 `FirearmItemData`인지 확인합니다.
  - 총기이고 `requiredAmmoType`이 있으면 `PlayerItemInventoryQuery.CountItem(requiredAmmoType)`로 남은 탄약 수를 계산합니다.
  - 총기가 아니거나 로컬 플레이어를 찾지 못하면 텍스트를 숨깁니다.
- 텍스트 표기는 간단히 `총알 12` 형태로 표시합니다.
  - 잔탄이 0이면 붉은색 계열, 1개 이상이면 흰색으로 표시합니다.
  - 기존 HUD와 맞춰 NEXON TMP 폰트, 검은 outline/shadow를 적용합니다.

**테스트**
- 총기를 장착하지 않았을 때 총알 UI가 보이지 않아야 합니다.
- 총기를 장착하면 오른쪽 아래에 현재 탄약 수가 표시되어야 합니다.
- 발사 후 탄약 아이템이 소모되면 숫자가 줄어야 합니다.
- 탄약이 0개가 되면 `총알 0`으로 표시되고 색상이 경고색으로 바뀌어야 합니다.
- 탄약을 줍거나 퀵슬롯/인벤토리로 이동해도 숫자가 다음 갱신 주기에 반영되어야 합니다.
- 멀티플레이에서는 로컬 플레이어 장착 총기와 로컬 인벤토리 기준으로만 표시되어야 합니다.

**가정**
- “총알 남은 갯수”는 탄창 탄수 문제가 아니라 현재 구현 기준의 **보유 탄약 수**를 의미합니다.
- 별도 UXML 수정 없이 코드 생성 UI로 추가합니다.
- `Time.timeScale = 0`이나 일시정지 상태와 무관하게 HUD는 로컬 장비/탄약 상태만 표시합니다.
