# 퀵슬롯 시스템 설정 가이드 (Quickslot System Guide)

이 문서는 새롭게 구현된 퀵슬롯(Quickslot) 시스템의 구성과 적용 방법을 설명합니다.

## 구성 요소 (Components)

1. **Quickslot UI 요소 (`QuickslotUI.uxml`, `QuickslotUI.uss`)**
   - 기존 `StatUI` 위치에 있던 UI 구조와 스타일시트를 `_Project/Scripts/01_PM/Quickslot/` 폴더로 이동 및 이름 변경하였습니다.
   - 단축키 슬롯 UI 화면을 구성합니다.

2. **QuickslotUIController.cs**
   - 퀵슬롯의 논리와 데이터를 관리하는 핵심 컨트롤러.
   - `Singleton(Instance)` 구조로 전역적으로 접근하여 아이템을 슬롯에 추가 및 조회할 수 있습니다.
   - UI Document와 연결해야 하며, 슬롯의 이름(예: `"Quickslot1"`, `"Quickslot2"`)을 UXML에서 찾아 시각적 아이템 아이콘 등을 갱신합니다.

3. **필드 아이템 스크립트 연결 (`ItemPickup.cs`)**
   - 필드에 배치된 줍거나 획득할 아이템 프리팹에는 **`ItemPickup`** 스크립트가 할당되어야 합니다.
   - 씬에 `ItemPickup`이 붙어있다면 인스펙터에서 `Item Instance`를 펼친 후 `Data` 항목에 주울 아이템의 `ItemData` 에셋을 연결해야 합니다.
   - 플레이어가 획득 시 `QuickslotUIController.Instance.AddItemToEmptySlot(itemInstance)`를 실행해 빈 슬롯에 채웁니다.

4. **입력 및 장착 처리 분리**
   - 숫자 키(Alpha1 ~ Alpha4) 입력 시, `PlayerEquipment.EquipItem()`를 호출하거나, 없는 경우 맨손 상태로 해제(`UnequipItem()`)합니다.
   - 플레이어 관련 원본 파일 수정 규칙을 지키기 위해 이 키 입력 로직은 **`QuickslotUIController` 업데이트 루프**에서 전담하여 처리하도록 구성되어 있습니다.

## 씬(Scene) 적용 및 연결 방법

1. **QuickslotUIController 설정**
   - 캔버스나 UI 빈 게임 오브젝트에 `UI Document`를 추가합니다.
   - `Source Asset` 필드에 이동시킨 `QuickslotUI.uxml`를 할당합니다.
   - 해당 게임 오브젝트에 `QuickslotUIController` 컴포넌트를 붙이고, `uiDocument` 필드에 `UI Document` 컴포넌트를 연결시켜 줍니다.

2. **UXML 요소 이름 매칭**
   - `QuickslotUIController.cs` 소스 내의 `var slot = root.Q<VisualElement>($"Quickslot{i + 1}");` 부분은 UI Builder에서 제작된 각 슬롯 컨테이너(`VisualElement`)의 고유 이름 속성과 동일해야 합니다 (예: `Quickslot1`, `Quickslot2`, `Quickslot3`, `Quickslot4`).
   - 내부의 아이콘을 띄울 엘리먼트는 `"Icon"` 이라는 이름으로 설정해야 정상적으로 배경에 아이콘이 렌더링 됩니다. 상황에 맞게 `uss` 클래스와 구조를 UI Builder에서 커스터마이징하세요.

3. **테스트 및 단축키**
   - 게임을 실행한 후 바닥에 있는 아이템과 상호작용(`E`키 등 설정된 상호작용 키) 하면 UI 빈 슬롯에 담깁니다.
   - 키보드의 `1`, `2`, `3`, `4`를 눌러 획득한 아이템을 스왑하거나 맨손으로 돌아갈 수 있습니다.
