# 적 비활성화 감지 → 상자 열기 → 열쇠 획득 → 문 열기 시스템 설정 가이드

## 1. 필요한 컴포넌트들

### 1.1 플레이어 설정
1. **사전 준비**: 씬 내에 시스템 인벤토리(`Systems.Inventory.Inventory`)가 구성되어 있어야 합니다.
2. 플레이어 오브젝트에 PlayerInventory.cs 컴포넌트를 추가
   - **Key Item Asset**: 그리드 인벤토리 시스템에서 생성한 열쇠 아이템 데이터(ItemDetails) 에셋을 드래그해서 반드시 연결해주세요.
3. 플레이어 오브젝트에 PlayerInteraction.cs 컴포넌트를 추가
   - Interaction Range: 3 (기본값)
   - Interactable Layers: 상호작용 가능한 레이어 설정
   - **Input System의 "Interact" 액션을 자동으로 사용** (E키 또는 설정된 키)

### 1.2 상자(TreasureChest) 설정
1. 상자 GameObject 생성
2. TreasureChest.cs 스크립트 컴포넌트를 추가
3. Collider 컴포넌트를 추가하고 IsTrigger = true로 설정
4. 다음 설정들을 인스펙터에서 구성:
   - **Target Enemies**: 감지할 적 게임오브젝트들을 드래그해서 배열에 추가 (빈 배열이면 조건 없이 바로 열림)
   - **Key Reward**: 획득할 열쇠 개수 (기본값: 1)
   - Interaction UI: 상호작용 UI GameObject
   - Interaction Text: 상호작용 텍스트 (TextMeshPro)
   - Chest Animator: 상자 애니메이션을 위한 Animator (선택사항)

### 1.3 문(LockedDoor) 설정
1. 문 GameObject 생성
2. LockedDoor.cs 스크립트 컴포넌트를 추가
3. Collider 컴포넌트를 추가하고 IsTrigger = true로 설정
4. 다음 설정들을 구성:
   - Interaction UI: 상호작용 UI GameObject
   - Interaction Text: 상호작용 텍스트 (TextMeshPro)
   - **Open Angle**: 문이 열릴 각도 (기본값: 90도)
   - **Open Speed**: 문 열리는 속도 (기본값: 2)
   - **Door Transform**: 회전할 문의 Transform (비워두면 자기 자신)
   - Door Blocker: 문을 막는 콜라이더 GameObject
   - Audio Source: 사운드 재생을 위한 AudioSource (선택사항)
   - Unlock Sound: 잠금 해제 사운드 (선택사항)
   - Open Sound: 문 열기 사운드 (선택사항)

## 2. UI 설정

### 2.1 상호작용 UI 생성
1. Canvas 하위에 UI Panel 생성
2. TextMeshPro 컴포넌트로 상호작용 텍스트 추가
3. 기본적으로 비활성화 상태로 설정

### 2.2 애니메이션 설정 (선택사항)
1. 상자 열기 애니메이션: "Open" 트리거 사용
2. 문 열기 애니메이션: "Open" 트리거 사용

## 3. 레이어 설정
1. 상호작용 가능한 오브젝트들을 특정 레이어에 배치
2. PlayerInteraction의 Interactable Layers에서 해당 레이어 선택

## 4. 태그 설정
플레이어 오브젝트에 "Player" 태그가 설정되어 있는지 확인

## 5. 작동 순서

### 5.1 적이 설정된 경우
1. TreasureChest의 Target Enemies 배열에 설정된 **모든 적**을 처치 (비활성화)
2. 상자가 자동으로 언락됨
3. 상자 근처로 이동하면 "E키를 눌러 상자를 열기" 메시지 표시
4. E키를 눌러 상자를 열면 **메인(Grid) 인벤토리에 지정된 열쇠 아이템이 실제 지급됨**

### 5.2 적이 설정되지 않은 경우 (빈 배열)
1. 게임 시작 시 상자가 바로 언락됨
2. 상자 근처로 이동하면 "E키를 눌러 상자를 열기" 메시지 표시
3. E키를 눌러 상자를 열면 **메인(Grid) 인벤토리에 지정된 열쇠 아이템이 실제 지급됨**

### 5.3 공통
5. 문 근처로 이동하면 메시지 표시 (인벤토리 안의 열쇠 유무를 자동으로 스캔)
6. E키를 눌러 문을 열면 메인 인벤토리 공간에서 직접 **열쇠 아이템 1개가 소모**되고 문이 90도 회전하며 열림

## 6. 중요한 설정 포인트
- **TreasureChest의 Target Enemies 배열**: 
  - 적을 설정하려면: Unity 에디터에서 Size를 원하는 만큼 설정하고 적들을 드래그
  - 조건 없이 바로 열리게 하려면: Size를 0으로 두거나 비워둠
- **문의 회전축**: 문이 올바른 방향으로 열리도록 문의 피벗 포인트를 문짝의 경첩 부분에 설정
- 적들이 죽을 때 `gameObject.SetActive(false)`로 비활성화되는지 확인 (적이 설정된 경우)
- 기존 EnemyHealth.cs는 전혀 수정하지 않음

## 7. 디버깅
- 콘솔 로그를 확인하여 각 단계가 정상적으로 작동하는지 확인
- **적이 설정된 경우**: 적이 비활성화될 때마다 상자 근처에서 인식 확인
- **적이 설정된 경우**: 모든 적이 비활성화되면 "🎉 모든 적을 처치했습니다! 보물상자가 잠금 해제되었습니다!" 메시지 출력
- 상자 열기 시 "📦 보물상자를 열어 X개의 열쇠를 획득했습니다!" 메시지 출력
- 문 잠김 시: "🔒 이 문을 열려면 열쇠가 필요합니다!" 및 UI에 "문 잠김     E" 표시
- 문 열기 시 "🔓 열쇠를 사용했습니다!" 및 "🚪 문이 열렸습니다!" 메시지 출력
- 메인 인벤토리가 씬에 없다면 `AddKeys()` 호출 시 Warning 로그 출력 주의

## 8. 장점
- **메인 인벤토리와의 완벽한 연동**: 더 이상 단순 변수(int)가 아니라 기획/기능적으로 확장 가능한 실물 아이템 기반 데이터(ItemDetails)로 관리됨
- **다중 열쇠 지원**: 여러 개의 열쇠를 모아서 여러 문을 열 수 있음 (중첩 스택 지원)
- **부드러운 문 애니메이션**: 90도 회전 애니메이션으로 자연스러운 문 열기
- **완전 유연한 조건**: 적 없음(바로 열림) ~ 원하는 만큼의 적 설정 가능
- **쉬운 테스트**: 배열을 비워두면 조건 없이 바로 테스트 가능
- 기존 Enemy 관련 스크립트를 전혀 수정하지 않음
- 특정 적들만 선택적으로 감지 가능
- 이벤트 시스템 없이 직접적인 상태 감지로 더 안정적
- Unity 에디터에서 드래그앤드롭으로 쉬운 설정

## 9. 문 설정 팁
- 문 GameObject의 피벗을 경첩 부분으로 설정 (문이 올바르게 회전하도록)
- Door Transform을 별도로 설정하지 않으면 자동으로 자기 자신을 사용
- Open Angle을 음수로 설정하면 반대 방향으로 열림
- Open Speed를 조절하여 문 열리는 속도 조정 가능
